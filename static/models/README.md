# Browser wellbeing model

Copy the trained ONNX artifact from Google Drive into this folder with this exact filename:

```text
mobilenet_v3_large_wellbeing.onnx
```

Source:

```text
Stress_Model_Finetune/Models/DDD/models/mobilenet_v3_large_wellbeing.onnx
```

The browser uses the ONNX file for local inference. Do not place the `.pt` training checkpoint here.
